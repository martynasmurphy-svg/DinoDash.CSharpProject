Dino Dash

Dino Dash is a 2D endless-runner game developed using C# and Windows Forms as part of a Software Systems Development project.

Features:
Player movement and jumping
Obstacle and collision detection
Lives system
Score tracking
Increasing difficulty
Physics revision quiz
XML-based score and leaderboard storage
Game audio
Technologies
C#
Windows Forms
XML
Visual Studio

What I learned!!!

This project developed my understanding of event-driven programming, debugging, data storage, testing and designing software functionality around user requirements.
