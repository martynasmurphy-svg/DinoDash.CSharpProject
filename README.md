# Dino Dash 🦖

## Overview

Dino Dash is a 2D endless-runner game developed in **C# using Windows Forms** as part of my Software Systems Development project.

The game combines traditional endless-runner gameplay with an **AS Physics revision quiz**, allowing players to test their physics knowledge before progressing into the main game.

## Features

- Player movement and jumping
- Obstacle and collision detection
- Lives system
- Score tracking
- Increasing game difficulty
- AS Physics revision quiz
- XML-based score and leaderboard storage
- Game audio
- Multiple game screens and navigation
- Tutorial system

## Technologies Used

- **C#**
- **Windows Forms**
- **XML**
- **Visual Studio**
- **Git/GitHub**

## Development

The project was developed using an event-driven programming approach. I used conditional logic, loops, arrays, file handling and object-oriented programming to implement the game's functionality.

I also carried out testing and debugging throughout development to identify and resolve programming, navigation and gameplay issues.

The project was created as an educational game to support **AS Physics revision** while providing an engaging and interactive gameplay experience.
