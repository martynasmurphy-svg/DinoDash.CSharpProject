# Dino Dash 🦖

A 2D endless-runner game developed in C# using Windows Forms as part of my CCEA GCE Software Systems Development project.

Dino Dash combines arcade-style gameplay with an AS Physics revision quiz. Players complete the quiz before progressing to the main game, where they avoid obstacles, build their score and aim to achieve a high ranking.

## Features

- **Endless-runner gameplay:** Control a dinosaur and avoid incoming obstacles.
- **Collision detection:** Detect interactions between the player and obstacles.
- **Scoring system:** Track the player's performance during gameplay.
- **Lives system:** Give players a limited number of lives.
- **Difficulty progression:** Increase the challenge as the game progresses.
- **Physics revision quiz:** Integrate AS Physics questions into the game experience.
- **Leaderboard and score storage:** Use XML-based file storage to retain player scores.
- **Windows Forms interface:** Build the game interface using C# and Windows Forms.
